This is the seed vault for the **Second Brain MCP server**. Every file in `vault/notes/`
and `vault/journal/` is a plain markdown file with YAML frontmatter — nothing is locked
in a database, so you can read and edit these directly in any editor too.

Start exploring by asking your assistant things like:

- "search my notes for MCP"
- "what are my open todos?"
- "give me the vault stats"
- "summarize [[MCP Fundamentals]]"

See [[MCP Fundamentals]], [[Second Brain Architecture]], [[Client Setup Cheatsheet]],
and [[Portfolio Ideas]] for the rest of the seed content.
