Other MCP servers worth building on top of [[Second Brain Architecture]] as
additional portfolio pieces, roughly ordered by how well they'd demo:

- [ ] A CRM-lite server (contacts + interaction log) for a small-business pitch
- [ ] A "codebase Q&A" server that indexes a repo's docs and exposes search
- [ ] A ticketing/helpdesk connector with scoped, read-only access
- [ ] An invoicing/quote generator for a freelancer client

Each one doubles as a sales demo for [[MCP Fundamentals]] — show a business owner
their own data becoming something Claude or Cursor can actually act on.
